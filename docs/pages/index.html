dryfire: ATT&CK coverage

The coverage layer CI builds from the rule tags on every push to main. Each technique is shaded by how many rules cover it; every rule behind a cell is tested on real attack data and its converted queries are run on real engines.

Open in ATT&CK Navigator

Or download layer.json and open it in the Navigator yourself. Source and rules: github.com/aeonstwilight/dryfire.
